# ✍️ content-strategy.md — استراتيجية المحتوى

> "النبرة الصحيحة تقنع قبل المحتوى الصحيح."

---

## 1️⃣ فلسفة المحتوى

### الفرق الجوهري:

معظم مواقع المطورين تكتب **عن نفسها**:
- "أنا خبير في..."
- "أقدم خدمات..."
- "لديّ سنوات خبرة في..."

هذا الموقع يكتب **عن العميل**:
- "مشكلتك تبدو كـ..."
- "هذا النوع من المشاريع يحتاج..."
- "كثير من أصحاب المشاريع يواجهون..."

### لماذا هذا الفرق مهم؟

الزائر لا يأتي ليعرف قصتنا — يأتي ليحل مشكلته. المحتوى الذي يتكلم عن مشكلته يُشعره بالفهم. وهذا الشعور هو أقصر طريق للثقة.

---

## 2️⃣ نبرة الموقع — Tone of Voice

### الوصف الدقيق:

```
هادئة       — لا صراخ، لا مبالغة، لا إثارة مصطنعة
مباشرة      — جملة واحدة تقول ما يمكن قوله في جملة
واثقة       — لا اعتذار، لا تقليل، لا تضخيم
عقلانية     — تخاطب العقل قبل المشاعر
محترمة      — تفترض أن القارئ ذكي
عملية       — كل جملة تُضيف قيمة أو تُسقط
```

### اختبار النبرة السريع:

إذا كانت الجملة تُناسب موقع بنك محترم — تُناسب هذا الموقع.
إذا كانت تُناسب إعلان طاقة مشروبات — لا مكان لها هنا.

## 3️⃣ قواعد الكتابة — ما نكتبه وما لا نكتبه

### ✅ نكتب:

**جمل قصيرة وحادة:**
```
❌ "أنا مطور ويب محترف ذو خبرة واسعة في مجال البرمجة وتطوير المواقع"
✅ "أبني حلولًا رقمية لمشاكل حقيقية."
```

**ندرة الادعاء، وفرة الدليل:**
```
❌ "نضمن أعلى جودة في السوق"
✅ "[اسم المشروع] — المشكلة كانت X، الحل كان Y، النتيجة Z"
```

**صوت إنساني، لا صوت مؤسسي:**
```
❌ "يسعدنا تلقي استفساراتكم والتواصل معكم في أقرب وقت ممكن"
✅ "أقرأ كل رسالة — أرد خلال 24 ساعة."
```

**المشكلة قبل الحل:**
```
❌ "خدماتنا تشمل تطوير الويب، التصميم، وتحسين الأداء"
✅ "عندما يكون موقعك بطيئًا، عميلك لا ينتظر — يذهب."
```

---

### ❌ لا نكتب:

| الأسلوب المحظور | لماذا؟ |
|---|---|
| "شغوف بالبرمجة" | كل مطور يقولها — لا تميز |
| "أحرص على رضا العميل" | ادعاء لا دليل عليه |
| "أسرع وأجود وأرخص" | الثلاثة لا تجتمع — يُقلل المصداقية |
| قوائم تقنيات بلا سياق | React، Node.js، etc. بلا سبب |
| "لا تتردد في التواصل" | كلمة ميتة لا قيمة لها |
| استخدام "نحن" للفرد | يُشير إلى عدم أصالة |

## 4️⃣ أنواع المحتوى في الموقع

### النوع الأول — محتوى التموضع (Hero / About)

**الهدف:** تثبيت صورة ذهنية واضحة ومختلفة.

**خصائصه:**
- أقصر ما يمكن مع أعلى كثافة معنوية
- لا تفاصيل — رؤية فقط
- يُجيب: من؟ لماذا؟ لمن؟

**مثال على الأسلوب:**
```
لا:
"مطور ويب مستقل بخبرة 5 سنوات في React وNode.js،
أقدم خدمات تطوير المواقع والتطبيقات."

نعم:
"أبني الأنظمة التي تعمل في الخفاء وتُظهر النتائج أمامًا."
```

---

### النوع الثاني — محتوى الإثبات (الأعمال / دراسات الحالة)

**الهدف:** الانتقال من الادعاء إلى الدليل.

**هيكل دراسة الحالة:**
```
1. العميل والسياق (في سطر واحد)
2. المشكلة الحقيقية (لا "بنيت موقعًا" — ما كانت المشكلة؟)
3. القرارات التقنية واللماذا (أين يظهر التفكير)
4. النتيجة (قابلة للقياس حيثما أمكن)
```

**ما لا يُدرج:**
- Screenshots بلا سياق
- قائمة التقنيات المستخدمة بلا مبرر
- نتائج مضخمة بلا دليل

---

### النوع الثالث — محتوى المنهجية (كيف أعمل)

**الهدف:** إثبات أن هناك تفكيرًا منهجيًا، لا تنفيذًا عشوائيًا.

**الأسلوب:**
- خطوات واضحة مع تفسير المنطق وراء كل خطوة
- "لماذا" في كل مرحلة، لا "ماذا" فقط
- يُظهر الاحترافية دون الادعاء بها

---

### النوع الرابع — محتوى التواصل (صفحة Contact / Footer)

**الهدف:** تحويل النية إلى خطوة بأقل احتكاك.

**الأسلوب:**
- مباشر وواضح
- يُدير التوقعات ("أرد خلال 24 ساعة")
- يُشجع دون ضغط

---

## 5️⃣ كيف نبني الثقة نصيًا؟

### الطريقة الأولى — الوضوح يبني الثقة

النص الواضح يُرسل رسالة ضمنية: "هذا الشخص يعرف ما يريد ويعرف ما يقول."
الغموض والتعقيد يُرسلان عكس ذلك.

### الطريقة الثانية — الصدق يبني الثقة

**نعترف بالحدود:**
```
"لا أعمل في مشاريع X لأنها خارج تخصصي."
← هذا يرفع الثقة لا يخفضها.
```

**لا ندّعي المستحيل:**
```
"أسلّم المشاريع الكبيرة خلال يومين."
← هذا يُسقط الثقة فوراً لمن يعرف.
```

### الطريقة الثالثة — الهدوء يبني الثقة

الشخص الواثق لا يُبالغ ولا يُلحّ. النبرة الهادئة تُقول:
"أنا واثق من قيمتي — ولست بحاجة لإقناعك بالقوة."

### الطريقة الرابعة — الاتساق يبني الثقة

التصميم والمحتوى والنبرة تتكلم بصوت واحد. أي تناقض يكسر الثقة:
"التصميم منضبط لكن النص مبالغ فيه" → رسالة متضاربة.

## 6️⃣ المصطلحات والكلمات — قائمة مرجعية

### كلمات نستخدمها:

```
نظام        حل          منهجية      سياق
بناء        تفكير       وضوح        دليل
قرار        أساس        مسار        نتيجة
```

### كلمات نتجنبها:

```
أفضل        ضمان        حصري        مميز
شغوف        متميز       رائد        متطور
يسعدنا      نرحب        نفخر        لا تتردد
```

---

## 7️⃣ النمو اللغوي للموقع

الموقع مصمم ليتطور:

```
المرحلة 1:  محتوى ثابت — تموضع + أعمال + تواصل
المرحلة 2:  مقالات — تحليلات تقنية وتجارب حقيقية
المرحلة 3:  محتوى متخصص — دراسات حالة موسّعة
```

**قاعدة النمو:** كل محتوى جديد يُضاف يجب أن يُعزز التموضع، لا يتعارض معه.
