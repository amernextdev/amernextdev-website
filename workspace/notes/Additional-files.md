# ملفات المشروع الإضافية

---

1. **`site.webmanifest`** — تعريف الموقع كـ PWA لإضافته على شاشة الهاتف

2. **`robots.txt`** — توجيه محركات البحث في فهرسة الموقع

3. **`sitemap.xml`** — إخبار محركات البحث بكل صفحات الموقع وأولوياتها

4. **`_headers`** — إضافة رؤوس HTTP مخصصة للأمان والأداء (Cloudflare)

5. **`_redirects`** — إعادة توجيه URLs وحماية 404 (Cloudflare)

6. **`.well-known/security.txt`** — قناة موحدة للإبلاغ عن ثغرات أمنية

7. **`humans.txt`** — تعريف بالأشخاص والأدوات خلف الموقع

8. **`README.md`** — تقديم المشروع وشرح كيفية تشغيله للمطورين

9. **`404.html`** — صفحة مخصصة للروابط غير الموجودة

10. **`favicon.ico`** — أيقونة الموقع في تبويب المتصفح

11. **أيقونات PWA (`icon-192.png`, `icon-512.png`)** — أيقونات التطبيق على شاشة الهاتف

12. **`apple-touch-icon.png`** — أيقونة الموقع على أجهزة iOS

13. **`CHANGELOG.md`** — سجل التغييرات التاريخي للمشروع

14. **`LICENSE`** — تحديد شروط استخدام الكود

15. **`wrangler.toml`** — إعدادات Cloudflare Pages (بناء، توجيه، متغيرات)

16. **`browserconfig.xml`** — تخصيص أيقونة الموقع على Windows / Microsoft Edge

17. **`og-image.jpg`** — صورة تظهر عند مشاركة الموقع على وسائل التواصل

18. **`CNAME`** — تحديد النطاق المخصص للمشروع (Cloudflare Pages)

19. **`.gitignore`** — تجاهل ملفات ومجلدات معينة في Git

20. **`security-headers-test.md`** — توثيق نتائج اختبار رؤوس الأمان

21. **`performance-report.md`** — تتبع تقارير أداء الموقع

22. **`.env.example`** — نموذج للمتغيرات البيئية المطلوبة

23. **`vercel.json`** — إعدادات Vercel (بديل لـ wrangler.toml)

24. **`tags.txt` / `keywords.txt`** — تتبع الكلمات المفتاحية المستهدفة لتحسين SEO

25. **مجلد `backup/`** — حفظ نسخ احتياطية من الملفات قبل التعديل
