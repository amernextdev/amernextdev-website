## 🎨 نظام الألوان

### الفلسفة
> "الألوان للوظيفة، ليس للزينة"

### الوضع الداكن (افتراضي)
```css
/* خلفيات */
--bg-primary: #0a0a0a     /* الخلفية الرئيسية */
--bg-secondary: #141414    /* بطاقات وأقسام */
--bg-tertiary: #1a1a1a     /* عناصر متداخلة */

/* نصوص */
--text-primary: #e5e5e5    /* النص الرئيسي */
--text-secondary: #a3a3a3  /* النص الثانوي */
--text-muted: #737373      /* نص خفيف */

/* حدود */
--border-primary: #2a2a2a  /* الحدود الأساسية */

/* لون مميز (استخدام محدود جدًا) */
--accent-primary: #3b82f6  /* للأزرار والروابط فقط */
--accent-hover: #2563eb
```

### قواعد الاستخدام
- ✅ استخدم Accent فقط: أزرار CTA، روابط عند hover، عناصر نشطة
- ❌ ممنوع Accent في: عناوين عادية، نصوص طويلة، خلفيات كبيرة
- ✅ تباين النصوص: WCAG AA كحد أدنى

## 📝 نظام الخطوط

### الخطوط المستخدمة
```css
--font-arabic: 'IBM Plex Sans Arabic'
--font-english: 'Inter'

/* الأوزان فقط */
--font-weight-normal: 400    /* نصوص عادية */
--font-weight-medium: 500    /* تمييز خفيف */
--font-weight-semibold: 600  /* عناوين */
```

### مقياس الأحجام (Major Third 1.250)
```css
--text-xs: 0.75rem      /* 12px - تفاصيل صغيرة */
--text-sm: 0.875rem     /* 14px - نصوص ثانوية */
--text-base: 1rem       /* 16px - النص الأساسي */
--text-lg: 1.125rem     /* 18px - فقرات افتتاحية */
--text-xl: 1.25rem      /* 20px - H4 */
--text-2xl: 1.563rem    /* 25px - H3 */
--text-3xl: 1.953rem    /* 31px - H2 */
--text-4xl: 2.441rem    /* 39px - H1 */
--text-5xl: 3.052rem    /* 49px - عناوين Hero */
```

### Line Heights
```css
/* عناوين */ line-height: 1.2
/* نصوص قصيرة */ line-height: 1.5
/* فقرات طويلة */ line-height: 1.7
```

### قواعد
- ❌ ممنوع: أحجام عشوائية، أوزان أقل من 400 أو أكثر من 600
- ✅ استخدم المتغيرات دائمًا، لا أحجام ثابتة

## ✍️ كتابة المحتوى

### المبدأ الأساسي
> "كل كلمة لها وظيفة. بدون وظيفة = احذفها"

### النبرة المطلوبة
- هادئة، واثقة (بدون غرور)
- مباشرة، احترافية (بدون تعقيد)
- صادقة (بدون تواضع مبالغ)

### ممنوع نهائيًا
```
❌ "الأفضل" "الأقوى" "الأسرع"
❌ "الحل السحري" "نتائج مضمونة"
❌ "استثنائي" "مذهل" "رائع"
```

### البدائل الصحيحة
```
✅ "موثوق" بدلاً من "استثنائي"
✅ "خبرة 5 سنوات" بدلاً من "خبير"
✅ "نتائج قابلة للقياس" بدلاً من "نتائج مذهلة"
```

### صيغة العنوان الرئيسي
```
[الفعل] + [الشيء] + [الصفة الوظيفية]

✅ مثال: "أبني أنظمة ويب موثوقة وقابلة للتوسع"
❌ خطأ: "مرحبًا، أنا أحمد!" أو "أفضل مطور"
```

### قواعد الكتابة
- جمل قصيرة: 15-20 كلمة كحد أقصى
- فقرات قصيرة: 2-3 أسطر
- قوائم فقط عند الضرورة (خطوات، ميزات محددة)
- لا مبالغة، لا عاطفة زائدة

## 🎯 تجربة المستخدم (UX)

### الفلسفة
> "الموقع يقود الزائر بهدوء، لا يدفعه بقوة"

### الثواني الأولى (Hero Section)
الزائر يسأل: "هل أنا في المكان الصحيح؟"

**يجب أن يرى:**
1. من أنت - بوضوح
2. ماذا تقدم - جملة واحدة
3. هل أنت مناسب له - ضمنيًا

### مسارات الزائر

**المسار السريع:**
```
الرئيسية → الخدمات → التواصل
(عميل جاهز للقرار)
```

**المسار البحثي:**
```
الرئيسية → الأعمال → من أنا → الخدمات → التواصل
(عميل يقارن الخيارات)
```

### نموذج التواصل المثالي
```
حقول مطلوبة فقط:
- الاسم
- البريد الإلكتروني
- نوع المشروع (قائمة منسدلة)
- الميزانية التقديرية (قائمة منسدلة - للفلترة)
- تفاصيل المشروع (50 حرف كحد أدنى)

✅ توضيح: "سأرد خلال 24-48 ساعة"
✅ صفحة شكر بعد الإرسال تشرح الخطوات التالية
```

## 📄 بنية الصفحات

### الصفحة الرئيسية
1. **Hero Section**
   - H1: العنوان الرئيسي
   - Subtitle: للمن + السبب
   - CTA: [اعرف المزيد]

2. **Value Proposition**
   - H2: "لماذا أعمل بطريقة مختلفة؟"
   - 3-4 نقاط قوة مختصرة

3. **الخدمات (نظرة سريعة)**
   - 3 بطاقات رئيسية

4. **الأعمال (عينة)**
   - 2-3 مشاريع مميزة

5. **CTA نهائي**

### صفحة الخدمات
1. مقدمة قصيرة
2. الخدمات التفصيلية (3-4 خدمات)
3. العملية (6 خطوات: اكتشاف، تخطيط، تطوير، اختبار، إطلاق، دعم)
4. CTA

### صفحة الأعمال
1. مقدمة
2. بطاقات المشاريع (4-6 مشاريع)
3. لكل مشروع صفحة Case Study:
   - المشكلة (1-2 جملة)
   - الحل (2-3 جمل)
   - التقنيات (قائمة بسيطة)
   - النتيجة (أرقام إن وجدت)

### صفحة من أنا
1. مقدمة شخصية (احترافية فقط)
2. الخبرة (سنوات، مجالات، تقنيات)
3. الأسلوب (المبادئ والقيم)
4. CTA

### صفحة التواصل
1. مقدمة
2. النموذج
3. FAQ (3-5 أسئلة)
4. طرق تواصل بديلة (بريد، LinkedIn)

## 🚫 الأخطاء الشائعة

### التصميم
```
❌ ألوان براقة أو تدرجات
❌ استخدام Accent في كل مكان
❌ أحجام خطوط عشوائية
❌ تباين ضعيف
```

### المحتوى
```
❌ "الأفضل" "الأقوى" "المذهل"
❌ قوائم طويلة بدون داعٍ
❌ فقرات طويلة (أكثر من 3 أسطر)
❌ عدم وضوح الـ CTA
```

### UX
```
❌ Pop-ups مزعجة
❌ CTAs كثيرة في كل قسم
❌ نماذج طويلة ومعقدة
❌ عدم توضيح ما يحدث بعد الإرسال
```

### التقني
```
❌ استخدام `\n` بدلاً من عناصر منفصلة
❌ ألوان ثابتة بدلاً من المتغيرات
❌ عدم اختبار على متصفحات مختلفة
❌ صور غير مضغوطة
```

## 📊 المبادئ الأساسية (TL;DR)

### الألوان
**90% من الموقع:** خلفيات رمادية داكنة + نصوص فاتحة  
**9%:** تفاصيل إضافية  
**1%:** Accent للتفاعل فقط

### الخطوط
**الوضوح > الجمال**  
3 أوزان فقط، مقياس ثابت، line-height مريح

### المحتوى
**كل كلمة لها وظيفة**  
لا مبالغة، لا حشو، صدق واحترافية

### UX
**التوجيه الهادئ، لا الدفع القوي**  
وضوح فوري، مسارات واضحة، فلترة ذكية

### الجودة
**البساطة المتقنة**  
كل شيء له سبب، لا عشوائية، اتساق تام
