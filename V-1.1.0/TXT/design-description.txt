# 🏗️ فلسفة تصميم الموقع – Ultimate Design Guide

الموقع شخصي لمطور Full-Stack، هدفه **إقناع العميل والجهات بأنك المطور المثالي، زيادة الثقة، وتحقيق تحويل عالي (Conversion)**.
كل تصميم وقرار لوني أو خطي له معنى، وليس للتزيين فقط.

---

## 1️⃣ Layout & Structure Philosophy

1. **Mobile-first**:

   * أغلب الزوار من الموبايل → كل العناصر عمودية، padding مناسب، tap-friendly.
   * الهيدر والفووتر، جميع الأقسام، تفاعل سلس بدون scrolling أفقي.

2. **Single Column Focus**:

   * كل قسم رئيسي (Hero, Services, About, Projects, Contact, Footer) يتبع عمود واحد أساسي.
   * الأعمدة المتعددة (Multi-column) فقط إذا كان Desktop view وتخدم المعلومات بوضوح.

3. **Visual Hierarchy**:

   * أهم عنصر في الصفحة → أكبر حجم + لون Accent / Gold
   * عناصر ثانوية → نصوص Secondary / Muted
   * عناصر أقل أهمية → Disabled / منخفض التباين

4. **Spacing & Rhythm**:

   * Padding/Margin: 20–50px حسب حجم القسم وDevice
   * Consistent vertical rhythm → يسهل على الزائر التصفح بدون إرهاق بصري

## 2️⃣ Color System Philosophy

### 🌑 Dark Mode (Default)

| الاستخدام        | اللون     | التفاعل / الملاحظة                  |
| ---------------- | --------- | ----------------------------------- |
| Background Main  | `#0B0F19` | خلفية كل الصفحة                     |
| Section / Card   | `#111827` | لتفريق أقسام                        |
| Surface Tertiary | `#1F2937` | عناصر ثانوية / أقل أهمية            |
| Border / Divider | `#2A3441` | فصل بصري خفيف                       |
| Text Primary     | `#F8FAFC` | محتوى أساسي                         |
| Text Secondary   | `#CBD5E1` | نصوص ثانوية / وصفية                 |
| Text Muted       | `#94A3B8` | ملاحظات، hints                      |
| Disabled         | `#64748B` | نصوص غير نشطة                       |
| Accent CTA       | `#3B82F6` | الأزرار الرئيسية، الروابط التفاعلية |
| Accent Hover     | `#2563EB` | تفاعل Hover                         |
| Brand Gold       | `#F5C842` | اللوجو، عناوين مهمة                 |

### ☀️ Light Mode (Optional)

* الخلفيات فاتحة (#FFFFFF, #F8FAFC)
* النصوص داكنة (#0F172A, #334155)
* Accent ثابت (#2563EB)
* Gold ثابت للبراند (#F5C842)

---

### 💡 قواعد استخدام الألوان

1. **80% خلفيات داكنة، 15% نصوص، 5% accent**
2. لا تخلط ألوان Brand / Accent في نفس العنصر
3. الألوان المهمة دائمًا تعكس الـHierarchy → Gold = Brand → الثقة والمهنية، CTA = أزرق → دعوة للتفاعل
4. استخدام Hover / Active states دائمًا للأزرار والروابط
5. لا تستخدم أكثر من 3 ألوان مختلفة في قسم واحد

## 3️⃣ Typography System

| النص             | الخط العربي          | الخط الإنجليزي | الوزن (Font Weight) | الاستخدام                    |
| ---------------- | -------------------- | -------------- | ------------------- | ---------------------------- |
| Headings H1      | IBM Plex Sans Arabic | Inter          | 600                 | عناوين أقسام، Hero           |
| H2/H3            | IBM Plex Sans Arabic | Inter          | 500                 | Sub-headings, Section Titles |
| Paragraph / Body | IBM Plex Sans Arabic | Inter          | 400                 | وصف نصوص / Content           |
| CTA / Buttons    | IBM Plex Sans Arabic | Inter          | 500–600             | أزرار، Call-to-action        |

### 💡 قواعد Typographic

1. Headings أكبر بنسبة واضحة من النصوص → hierarchy واضحة
2. Line-height: 1.5–1.75 للقراءة الطويلة
3. Letter-spacing: 0–0.5px للعناوين لتوازن المسافات
4. Body text → weight 400، Secondary text → weight 500/Muted
5. Headers + CTA → وزن 500–600

---

## 4️⃣ Section-wise Design Philosophy

### Hero Section

* Background: Dark Mode / Gradient بسيط
* Layout: Flex، اللوجو أو أي أيقونة على اليمين (Desktop)، فوق النص على الموبايل
* Typography: H1 كبير + وصف قصير [وصف الجمله]
* CTA: زر رئيسي باللون الأزرق (#3B82F6) مع Hover (#2563EB)

### Services / Projects / About / Contact

* Sections متعددة، كل Section:

  * Background: Main أو Card surface
  * Title H2 (500)
  * Body Text (400)
  * Accent elements: زر + hover interactions
  * Cards / Grid: max 3 per row (Desktop), عمودي على Mobile

### Footer

* Single column
* نصوص: Identity → Primary text, Email/Phone → Links accent hover
* Optional: Back to Top → small accent icon
* Padding: 40px Desktop, 20px Mobile

---

## 5️⃣ Shadow / Border / Depth

| العنصر             | Shadow / Border                                              |
| ------------------ | ------------------------------------------------------------ |
| Cards              | `0 4px 6px rgba(0,0,0,0.5)` (Dark) / rgba(0,0,0,0.1) (Light) |
| Modals / Popups    | `0 10px 15px rgba(0,0,0,0.6)`                                |
| Buttons            | subtle shadow + transition hover                             |
| Inputs / Textareas | border-light #2A3441 + focus border accent (#3B82F6)         |

---

## 6️⃣ Interaction / Hover / Animation Rules

1. Hover على الأزرار → تغيير لون الخلفية أو النص للـAccent Hover
2. Links → underline أو color change عند Hover
3. Smooth transitions: `transition: all 0.3s ease-in-out`
4. Buttons CTA → slight scale-up hover (`transform: scale(1.05)`)

## 8️⃣ Practical Guidelines for AI Assistant

* كل نص → استخدم `[وصف الجمله]` placeholder
* كل Section → له background / typography / spacing محدد
* كل CTA → accent color + hover
* Cards → consistent shadow + border + responsive grid
* Footer → single column, vertical order, clickable links
