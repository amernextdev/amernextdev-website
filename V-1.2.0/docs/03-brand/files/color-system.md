# 🎨 color-system.md — نظام الألوان

> "اللون ليس جمالًا — هو توصيل. كل لون يقول شيئًا قبل أن تُقرأ كلمة واحدة."

---

## 1️⃣ فلسفة الألوان في هذا الموقع

### القاعدة الذهبية:

> **القليل بدقة أقوى من الكثير بعشوائية.**

الموقع يعمل بثلاثة ألوان أساسية فقط — لا أكثر في المرحلة الأولى. كل لون إضافي يُضعف التركيز البصري ويُشوّش الرسالة.

### ما يجب أن تُحقّقه الألوان:

```
الشعور المطلوب:   موثوق — منضبط — احترافي — هادئ
ليس:             مبهج — مثير — زاهي — عشوائي
```

### السبب النفسي وراء الاختيار:

الألوان الداكنة والمحايدة ترتبط نفسيًا بالخبرة والعمق والثقة. الألوان الزاهية ترتبط بالطاقة والتسلية — لكنها تتعارض مع شخصية "المهندس الهادئ" التي بنيناها في `brand-identity.md`.

## 2️⃣ Palette الرئيسية

### اللونان الأساسيان:

---

#### 🖤 Primary — الأساس الداكن

```
الاسم:     Ink / الحبر
HEX:       #0F1117
RGB:       15, 17, 23
HSL:       230°, 21%, 7%
```

**يُستخدم في:**
- خلفية الصفحة الرئيسية (dark mode)
- نص العناوين الكبيرة على الخلفيات الفاتحة
- الأشكال والعناصر الفاصلة الرئيسية

**لماذا هذا اللون؟**
داكن جداً لكنه ليس أسوداً حتى. يحمل دفئاً طفيفاً يمنع الإحساس بالبرودة المفرطة — توازن بين الاحتراف والإنسانية.

---

#### ⚪ Secondary — الأساس الفاتح

```
الاسم:     Chalk / الطباشير
HEX:       #F5F4F0
RGB:       245, 244, 240
HSL:       45°, 14%, 95%
```

**يُستخدم في:**
- خلفية الأقسام الفاتحة
- نص أساسي على الخلفيات الداكنة
- مساحات التنفس البصري

**لماذا هذا اللون؟**
أبيض دافئ لا بارد. يتجنب البياض الصارخ (#FFFFFF) الذي يُعطي إحساس بالتعقيم. الدفء هنا يتسق مع شخصية العلامة الإنسانية.

---

### لون التمييز — Accent:

---

#### 🔵 Accent — نقطة التركيز

```
الاسم:     Signal / الإشارة
HEX:       #2563EB
RGB:       37, 99, 235
HSL:       221°, 83%, 53%
```

**يُستخدم في:**
- أزرار CTA الرئيسية فقط
- الروابط الداخلية النصية
- نقاط التأكيد البصري المحدودة
- Hover states على العناصر التفاعلية

**قواعد صارمة على Accent:**
```
✅ زر CTA واحد رئيسي في كل section
✅ روابط نصية داخل المحتوى
✅ Underline أو نقطة تأكيد واحدة

❌ أكثر من عنصر Accent في نفس الـ viewport
❌ خلفيات كاملة بهذا اللون
❌ نص عادي (غير تفاعلي) بهذا اللون
❌ الاستخدام الزخرفي بلا وظيفة
```

**لماذا الأزرق تحديداً؟**
الأزرق هو اللون الأعلى ارتباطاً بالثقة والمصداقية في الأبحاث النفسية. ليس مصادفة أن البنوك والمؤسسات التقنية الكبرى تعتمده. هنا نستخدمه بحذر ليُعزز قيمة الموثوقية دون تشبّع.

## 3️⃣ ألوان الحالة — Semantic Colors

هذه الألوان تظهر فقط في سياقات وظيفية محددة:

| الحالة | HEX | الاستخدام |
|---|---|---|
| **Success** | `#16A34A` | رسالة نجاح الإرسال، حالات التحقق الإيجابي |
| **Warning** | `#CA8A04` | تنبيهات أو ملاحظات مهمة |
| **Error** | `#DC2626` | رسائل الخطأ في النماذج فقط |
| **Muted** | `#6B7280` | النصوص الثانوية، التسميات، الـ Placeholders |

> [!WARNING]
> ألوان الحالة تظهر فقط في السياق الوظيفي المحدد. لا تُستخدم للزينة أو التنويع البصري.

## 4️⃣ نظام الطبقات — Layers

الموقع يعمل بطبقتين رئيسيتين:

### الطبقة الداكنة (Dark Sections):

```
خلفية:      #0F1117  (Primary)
نص رئيسي:   #F5F4F0  (Secondary)
نص ثانوي:   #9CA3AF
فاصل:       rgba(245, 244, 240, 0.08)
Accent:     #2563EB
```

### الطبقة الفاتحة (Light Sections):

```
خلفية:      #F5F4F0  (Secondary)
نص رئيسي:   #0F1117  (Primary)
نص ثانوي:   #6B7280
فاصل:       rgba(15, 17, 23, 0.08)
Accent:     #2563EB
```

## 5️⃣ قواعد التباين — Contrast Rules

### المعيار المعتمد: WCAG AA كحد أدنى

| التركيبة | نسبة التباين | المعيار |
|---|---|---|
| `#F5F4F0` على `#0F1117` | 17.5:1 | ✅ AAA |
| `#0F1117` على `#F5F4F0` | 17.5:1 | ✅ AAA |
| `#2563EB` على `#F5F4F0` | 5.9:1 | ✅ AA |
| `#9CA3AF` على `#0F1117` | 5.1:1 | ✅ AA |

> [!NOTE]
> لا يُستخدم لون على خلفية إلا بعد التحقق من نسبة التباين. أداة التحقق: [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)

## 6️⃣ متى يُستخدم كل لون — جدول المرجع السريع

| اللون | متى نستخدمه | متى لا نستخدمه |
|---|---|---|
| `#0F1117` Ink | Hero section، خلفيات رئيسية، عناوين H1 | تفاصيل صغيرة، Captions |
| `#F5F4F0` Chalk | نص على داكن، خلفية فاتحة، مساحات بيضاء | عناصر تفاعلية، Buttons |
| `#2563EB` Signal | CTA واحد فقط، روابط نصية | ديكور، كتل نصية كاملة |
| `#6B7280` Muted | Metadata، Dates، Tags، Captions | عناوين، نص رئيسي |

## 7️⃣ CSS Variables — نظام المتغيرات

```css
:root {
  /* ── Core Colors ── */
  --color-ink:     #0F1117;
  --color-chalk:   #F5F4F0;
  --color-signal:  #2563EB;

  /* ── Semantic ── */
  --color-success: #16A34A;
  --color-warning: #CA8A04;
  --color-error:   #DC2626;
  --color-muted:   #6B7280;

  /* ── Surfaces ── */
  --surface-dark:  var(--color-ink);
  --surface-light: var(--color-chalk);

  /* ── Text ── */
  --text-on-dark:  var(--color-chalk);
  --text-on-light: var(--color-ink);
  --text-secondary: #9CA3AF;

  /* ── Borders ── */
  --border-dark:   rgba(245, 244, 240, 0.08);
  --border-light:  rgba(15, 17, 23, 0.08);
}
```

> [!NOTE]
> استخدم دائماً المتغيرات، لا قيم HEX مباشرة في CSS. هذا يضمن الاتساق ويُسهّل التعديل المركزي لاحقاً.

## 8️⃣ ما لا يُوجد في هذا الموقع (عمداً)

```
❌ Gradients معقدة متعددة الألوان
❌ ألوان نيون أو Glow effects
❌ Shadows ملونة (فقط neutral shadows)
❌ أكثر من 3 ألوان في viewport واحد
❌ ألوان مختلفة لنفس نوع العنصر
```
