# عامر — بنية تحتية للهوية المهنية

موقع مهني مبني كمنظومة تموضع واستقطاب، لا كـ portfolio عرض أعمال.
كل قرار فيه — من اللون إلى بنية الكود — محكوم بدستور استراتيجي موثَّق.

---

## ما هذا المشروع

هذا ليس معرض أعمال.
هو منظومة تصفية وإرسال إشارات ثقة مصمَّمة لمقيّم محدد: صانع قرار تقني لديه مشكلة على مستوى الأنظمة.

الموقع يعمل على ثلاث طبقات:

**0–3 ثوانٍ** — إشارات السلطة البصرية تُرسي المصداقية قبل قراءة كلمة واحدة.
**3–30 ثانية** — اللغة الدقيقة وكثافة المعلومات تُؤكد العمق التقني.
**30+ ثانية** — نماذج العمل المُقدَّمة بإطار مشكلة ← قرار معماري ← نتيجة تُغلق الحلقة.

## المبادئ الحاكمة

المشروع محكوم بمنظومة وثائقية من **42 ملفاً** موزعة على **7 مجلدات**:

| المجلد | الوظيفة |
|--------|---------|

| `03-technical/` | مبرر المكدس التقني، معمار CSS/JS، المعايير |
| `04-quality/` | ميزانيات الأداء، SEO، إمكانية الوصول |
| `05-evolution/` | خطط الهجرة عبر 5 مراحل |
| `06-operations/` | الإطلاق، التغييرات، الإصدارات، دورات المراجعة |
| `07-reference/` | قاموس المصطلحات، مخططات البنية، جداول الهجرة |

ابدأ بـ [`docs/README.md`](./docs/README.md) للحصول على دليل القراءة الكامل.

## المكدس التقني (المرحلة الأولى)

| الطبقة | الاختيار | المبرر |
|--------|---------|--------|
| البنية | HTML5 دلالي | محتوى ثابت، ترميز جاهز للهجرة |
| التنسيق | CSS خالص + متغيرات | لا تبعية build، مسار مباشر لـ design tokens |
| السلوك | Vanilla JS ES6 modules | لا overhead إطار عمل، استخراج React نظيف لاحقاً |
| البيانات | ملفات JSON محلية | الـ schema يطابق شكل API المستقبلي |
| الاستضافة | Cloudflare Pages | Edge CDN، zero config، إعداد مجاني |

لا frameworks. لا build tools. لا تبعيات بدون عائد مُبرَّر.

## التشغيل المحلي

```bash
# تشغيل مباشر — لا build مطلوب
npx serve . -p 3000

# أو
python3 -m http.server 3000

# التحقق قبل النشر
npx lighthouse http://localhost:3000 --output=html
```

## النشر على Cloudflare Pages

```bash
# اربط الـ repository بـ Cloudflare Pages:
# Build command:        (فارغ — ملفات ثابتة)
# Build output dir:     /
# Root directory:       /
```

عند كل push على `main`، Cloudflare Pages ينشر تلقائياً.
التراجع متاح من لوحة تحكم Cloudflare أو عبر `wrangler rollback`.
