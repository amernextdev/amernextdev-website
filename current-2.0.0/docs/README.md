# 🗂️ docs/ — لوحة التحكم

> **نظام التوثيق الاستراتيجي** لموقع مطور برمجيات مستقل.
> هذا المجلد ليس مجرد ملفات — بل هو **العقل المدبر** للمشروع كله.

---

## 📌 ما هذا المشروع؟

هذا الموقع هو **نظام تموضع مهني** (*Professional Positioning System*) لمطور برمجيات مستقل متخصص في بناء حلول رقمية متكاملة. وظيفته الجوهرية ليست عرض المهارات، بل **بناء الثقة وتصفية العملاء** قبل أول تواصل.

الموقع يتحدث بلغة واحدة:

> "أنا لا أكتب كودًا — أنا أبني أنظمة تحل مشاكل."
