الصفحة: Global  |  القسم: Header / Navigation
الهدف: تنقل صامت يخدم البنية — لا يستأثر بالانتباه ولا يُضعف الترشيح
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

المكونات النصية:

1. site-identity — Display / Wordmark
   "الاسم أو الرمز الذي يُثبت الهوية — نقطة ارتساء بصري لا شعار ترويجي"
   ملاحظة: يربط بـ Home — لا tagline بجانبه، لا icon، لا وصف.

2. nav-link: Work — label
   "يقود إلى صفحة Work — إثبات الكفاءة على مستوى الأنظمة"
   ملاحظة: الكلمة الواحدة كافية — لا وصف تحتها، لا hover tooltip.

3. nav-link: Approach — label
   "يقود إلى صفحة Approach — المنهجية وطريقة التعاون"
   ملاحظة: ترتيبه بعد Work يعكس تسلسل القرار الإدراكي للمقيّم.

4. nav-link: Notes — label
   "يقود إلى صفحة Notes — السلطة المعرفية المستمرة"
   ملاحظة: ليس "Blog" ولا "Articles" — الاسم الوظيفي هو الرسالة.

5. nav-link: Contact — label
   "يقود إلى صفحة Contact — مسار التواصل الانتقائي"
   ملاحظة: يأتي أخيراً بقصد — الترتيب يعكس منطق الفلترة: الإثبات أولاً، التواصل آخراً.

6. theme-toggle — icon-button (لا label)
   "أيقونة وظيفية تُبدّل بين الوضع الداكن والفاتح — بلا نص مرافق"
   ملاحظة: أيقونة وحيدة بلا label — إضافة نص ("Dark / Light") يُحوّلها إلى عنصر بصري زائد يتعارض مع Section XII.2.

7. language-toggle — text-switch (EN / AR)
   "مفتاح نصي ثنائي يبدّل اللغة مباشرة — لا dropdown"
   ملاحظة: Dropdown يوحي بخيارات متعددة غير موجودة — نصّان ثابتان (EN / AR) أدق معمارياً وأوضح وظيفياً؛ الدستور يُفضّل الدقة على الإيحاء.

ملاحظة معمارية — مكوّن غير مطلوب لكن ذو وظيفة:
لا يُقترح أي مكوّن إضافي. الـ Header في هذا النظام يخدم التنقل فقط —
أي إضافة (CTA، tagline، social icons) تتعارض مع Law L-03
وتكسر صمت الـ perception layer.
